# Aryan Bansal Portfolio (VS Code)

This is a static HTML/CSS/JavaScript version of the current Hatchable portfolio.

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Install the **Live Server** extension (Ritwick Dey).
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Files
- `index.html` — page content and sections
- `styles.css` — main dark/gold theme, lamp intro, projects, education, achievements
- `profile-hero.css` — About / flip ID card / quick facts layout
- `app.js` — lamp pull interaction, greeting, scrolling and reveal animations
- `nsut-campus.jpg` — NSUT campus image used in the education section

## Editing tips
- Change text, links, project descriptions and sections in `index.html`.
- Change colours, layout, card sizing and responsive breakpoints in the CSS files.
- Change interactions in `app.js`.
- Your GitHub and LinkedIn links are already included.
- The ID portrait currently uses `AB` as a placeholder. Replace the `.id-portrait` initials with an `<img>` when you are ready to add your photo.

This is a front-end export. It does not connect to Hatchable's deployment workflow automatically; local edits will not change the hosted site until you deploy them separately.
